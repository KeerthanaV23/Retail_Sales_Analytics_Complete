# Retail Sales & Customer Analytics

A beginner-friendly analytics project built with Python, Pandas, SQL and Streamlit.

## Features
- Sales KPI dashboard
- Monthly revenue trends
- Category performance
- Top products
- Customer analysis
- Region-wise performance
- SQL analytics queries

## Run
1. Create a virtual environment:
   `python -m venv venv`
2. Activate it on Windows:
   `venv\Scripts\activate`
3. Install packages:
   `pip install -r requirements.txt`
4. Run:
   `streamlit run app.py`

The app uses the included sample dataset in `data/sales_data.csv`.
